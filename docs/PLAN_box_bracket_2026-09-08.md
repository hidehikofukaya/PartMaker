## 1. 実車 002-024 の分解

（bolt3 / mounting_hole1 / other_hole3 / weld6）。面グラフ（大平面＋つないでいる曲げ）は:

```

                      |  35°/R8.8                 |  R5.8
   #25 (44×33) --76°/R7.8-- #33 (101×41)        #39 (57×18)
      |89°/R8.8              |89°/R8.8            |  R5.8
      +--------- #54 ハブ (145×105) -------+      |

              #3 (114×71) --88°/R5.8--   #58 (70×26) --90°/R11.2-- #57 (86×48)
                |68°/R5.8                     |
              #14 (79×59) --12°/R10.8-- #15 (122×29, weld2)
```

読み方:

- **ハブ #54 に 5 枚のパネルが折れて付く**（#3 / #25 / #33 / #57 / #58）。うち #25–#33、
  #57–#58、#3–#58 は**互いにも曲げでつながっている** = ハブの隣り合う辺に立った壁が
  角で連結されている。その連結の曲げは短い（#34 は弧長 2.4mm、#10 は 23mm、#47 は 29mm）ので、
  「別のパネル」ではなく**角のフィレット**である。
- 小さな b-spline 面が 16 枚（各 15〜270mm²、合計で面積の 1〜2%）。これは 3 枚のパネルが
  出会う頂点のブレンド = **絞りの隅**。合成側の `drawn_tray` で作っているものと同じ。
- **深さ2以上のパネル**がある: #3 → #55 / #14 / #39、#39 → #56、#14 → #15。
  壁からさらに折り出したフランジで、そこにボルトと溶接が載る。
- 当初「ハブを横切るリブ」と読んだ #33/#25 の 3 サイクルは、上記のとおり
  **隣り合う 2 枚の壁とその角**だった。リブは無い。

したがって 002-024 の骨格は **「凸多角形のハブ + 任意の辺に立つ壁 + 隣り合う壁の角の連結 +
壁の上の深さ2フランジ + 溶接タブ」**。これは `drawn_tray`（ハブ四角 + 壁3 + 継ぎ目2 の固定形）の
一般化そのもので、新しいビルダーを一から書く必要はない。

## 2. 設計

### 2.1 ビルダー（`build_box_bracket`）

手順は `drawn_tray` と同じ **「鋭いエッジで縫ってからフィレット」**（腕を生やしてから連結する
手法は過去に大失敗している。2026-09-06 のユーザー指摘）。

1. ハブ（凸多角形、反時計回り。壁の無い辺には腕の根本の頂点を挟む）と壁を鋭いエッジで縫合。
   壁 i は辺 i を軸に裏側へ折る。頂点 k で隣り合う壁（辺 k−1 の右端と辺 k の左端）は
   **2 枚の壁の平面の交線**で互いにトリムする（`box_frames`）。
2. 壁の根本 N 本 + 継ぎ目 M 本を **すべて同じ半径**で OCCT フィレット。頂点に出るブレンド面が絞り。
3. 深さ2のフランジは壁の上端の部分区間から回転掃引で折る（`_split_top_line` で輪郭に根本の頂点を入れる）。
4. 腕（タブ）は壁の無い辺の根本エッジから折る。最後に全部縫合してゲート。

### 2.2 実測で分かった制約（2026-09-08）

| 事実 | 根拠 |
|---|---|
| 3〜6 枚の壁で角を**全部**閉じてもフィレットは収束する | 15 ケースの探り: 三角/四角/五角/六角のハブで全角連結 → 収束（`rect_w0123_all`、`hex_w_all`、`tri_w012_all`） |
| **隣り合う壁の角を開けたままにはできない** | 折れ角 75° の隣接 2 壁を開けると不収束（`rect_w01_open75`）。2 本の根本フィレットが頂点で衝突する。開けたければハブの輪郭に切欠きを入れて根本を離す必要がある（第2期） |
| 角のR は 4〜10 で収束する。半径は 1 部品で**そろえる** | `rect_w0123_r4` / `r10` とも収束。半径が違うと頂点のブレンドの縁が自由曲線になりゲートAで落ちる（2026-09-06 の絞りトレイの教訓をそのまま適用） |
| 壁の高さが継ぎ目どうしで違ってよい（低い方に継ぎ目の端を置き、高い方は上端を細らせる） | `h_big_mix`（高さ 12〜55 の 4 壁 + 全角連結）で収束 |
| 折れ角は 60〜120 まで通る | `fold60` / `fold120` / `fold_mix` |
| 深さ2のフランジは内向き・外向きどちらも通る | `f_out` / `f_in` / `f_soft` / `f_trap` / `f_tabs` / `f_box4` |
| 深さ2のフランジと壁のタブは共存できる（根本がタブの占有幅に掛からなければ） | `f_with_tab_on_wall` |
