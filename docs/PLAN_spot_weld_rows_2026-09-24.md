## 2. 仕様

### 2.1 列の置き方（共通）

- 列は「縁に平行な平らな帯」の上に置く: 縁から d、両端からも d 以上空け、長さ `usable = 幅 − 2e` に
  `n = round(usable / p) + 1` 点を等間隔（`usable < p/2` なら中央に 1 点）。実際の間隔は p の 0.8〜1.33 倍に収まる。
- 列を置く面の平らな長さ L は `L ≥ d + 3 + 1`（曲げ接線から 3mm 以上）。
- 溶接点の必要座面半径は `None`（`point_radii` の該当要素が `null`）。ボルトの座面ゲートと座面比から外す。

### 2.2 occt23 chunk_02（パネル + 溶接列）

- 壁腕: 曲げで区切られた各区間 × 両側の空き区間（30mm 以上）に、確率 0.85 で**区間全長**の壁腕を立てる。
  高さ（平らな長さ）15〜40mm（かつ d + 4 以上）、折れ角は従来の壁腕（75〜90 度）。
- 各壁腕の先端から d の位置に列。
- 腕（タブ付き含む）は残りの空き区間に従来どおり。ボルト点（アンカー 2 + 腕 + 平地）は従来どおりで、
  合計が 40 を超えない範囲で置く。**合計 20〜40 点でなければ引き直し**。

### 2.3 occt22 chunk_02（多面ブラケット + 溶接列）

- 群は `bend` / `draw` を各 150（`plate` は壁が無く列を置けないので除く）。
- **ハブを 1.8 倍**にする（試作: 002-024 の寸法のままだと外周 300〜600mm にピッチ 30〜70 の列しか載らず、
  溶接 2〜11・合計 10〜16 で下限 10 に張り付いた。1.8 倍で合計 中央 12〜13・最大 27）。
- 壁の高さの下限に `接線長 + d + 4` を足す（絞り比で高さを削った後に足りない壁には列を置かない）。
- 列は壁の上端（タブと深さ2フランジの根本を避けた空き区間ごと）、深さ3の付いていない深さ2フランジの先端、
  腕の先端に置く（試作でタブ付きの壁を丸ごと除くと溶接 0 の部品が多かったため、空き区間に変えた）。
  列を置いた壁には面の点を置かない。ハブ・腕・タブの点は従来どおり。**合計 10〜30 点でなければ引き直し**。

### 2.4 ゲートと出力

- 生成ゲート（`_check_bearing_margin`）: 半径が `None` の点は溶接の契約（自由縁 ≥5 − 0.3、他の辺 ≥3 − 0.3）で判定。
- `batch_generate`: `point_kinds` に従い joints を `weld` / `mounting_hole` で書き分ける。`structure.welds` に溶接点数。
- `tools/backfill_structure.py`: 座面比はボルト点だけ。溶接点は `spot_weld_d_edge_mm`（自由縁まで）と
  `spot_weld_d_bend_mm`（他の辺まで）を実測して `structure` に入れる。

### 2.5 変種・別シード

- chunk_02 の変種は今回作らない（依頼に無い）。ただし別シードが列の載った壁腕の高さを変えないよう、
  `reseed_panel` は点の載った壁腕を固定する（将来の事故防止）。

## 3. 手順

1. 実装（families / occt_build / annotate / batch_generate / backfill_structure）とテスト。
2. 試作（各族 20 部品）→ 図で確認 → ゲート落ち率・点数分布・d / ピッチの実測を見る。
3. 本生成（各 300）→ `backfill_structure` → 世代照合 → 回答書（AMS 宛）。
