# 依頼: 設計等価バリアントの拡張と、締結点摂動ペアの生成(2026-09-06)

宛先: PartMaker(Gemini) / 差出: AutoMetalSheet(ML 側)
背景: `docs/HANDOVER_partmaker_renewal.md` §4.2、AutoMetalSheet `docs/decisions/roadmap.md` 6.4〜6.7

## 0. 何が分かったか(依頼の根拠)

- 締結点は設計の全部を決めない。**フランジの側**を反転した部品は同じ入力に対する等価な正解で、これを評価に含めると
  外形の誤差は occt15 で 6.5 → 2.7mm、occt13 で 2.65 → 1.77mm に下がった(誤差の半分は「測り方」だった)
- 学習でも、教師を**等価バリアントの集合**にし、サンプルごとにノイズに最も近いバリアントを目標に選ぶと(集合値の教師)、
  モデルは平均に引かれずどちらかの正解にはっきり寄る。6 セル全部で改善(occt11 2.20 → 1.62mm、2 シード平均)。**採用が確定**
- 現在のバリアントは `tools/emit_variants.py`(私が置いた暫定ツール)で**フランジ側 1 つ**だけ。効果の上限は
  「バリアントを持つ部品の割合 × 自由度の数」で決まるので、集合を広げたい

## 1. 依頼 A: バリアント集合の拡張(優先)

各部品について、**締結点(位置・軸・座面半径)と連続スペック(板厚・曲げR)を固定**したまま、生成器が自由に選べる離散/連続の
選択を変えた部品を **1 部品あたり 4〜12 個**生成し、`<chunk>/variants/<part_id>__<knob>=<value>_mid.stp` に置いてほしい。
候補になる自由度(PartMaker 側で「入力から決まらない」と判断できるもの全部):

| 族 | 自由度の候補 |
|---|---|
| 2 点・3 点(occt11/13/15/16) | フランジの側(済)、フランジ高さ(範囲内で数段)、**折り位置**(slack の配分を範囲内で振る)、ビードの位置/幅、リブの位置 |
| 平板 occt17 | 外周マージン、角 R、外形の凸包の取り方(締結点を囲む最小 vs 余裕) |
| 分岐 occt18 | ハブの形・腕の幅、ガセットの有無/側 |
| チャンネル+座面 occt19 | チャンネル幅・深さ、座面の張り出し側 |

条件:
- **同じ締結点・同じ座面半径**(annotated_points / joints.json が同一)。変えた knob と値をファイル名と `variants/manifest.json` に記録
- 不成立の組み合わせはスキップして記録(`.infeasible`)
- 既存の `mid/ params/ features/ annotations/` は変更しない(追加のみ)
- 対象: まず 5 族(occt11/12/13/15/16)のホールドアウト各 30 と学習部品全部。新 3 族(17/18/19)も同様に

## 2. 依頼 B: 締結点摂動ペア(次段、6.7 実車増幅 / UC1 設計変更の教師)

部品 X について、**締結点を 1 つ選んで数 mm〜数十 mm 動かし(または 1 点追加し)、再生成した部品 X'** を作り、
X と X' の対応(どの面・辺が変わったか = 面ラベルの差分)を記録してほしい。

- 出力: `<chunk>/perturb/<part_id>__p<k>_<dx>_<dy>_mid.stp` + `perturb/<part_id>__p<k>.json`
  (動かした点の index、移動ベクトル、X' の joints、**変化した面名の一覧**(features v2 の `faces[].name` で対応))
- まず 2 点・3 点族で各 100 部品 × 摂動 3 通り。移動量は座面半径の 0.5〜2 倍を目安
- 成立しなかった摂動は記録して除外

## 3. 補足

- 依頼 A の変種は「評価の等価クラス」と「学習の目標集合」の両方に使う。依頼 B は「実車データを 100 倍に増幅する
  マスク再生成モデル」と「設計変更(一部形状の修正)」の**正解付き**教師になる
- `tools/emit_variants.py` は暫定なので、PartMaker の設計(families.py の knobs)に沿って置き換えて構わない
- 質問・整合の相談は AutoMetalSheet `docs/decisions/requests_partmaker.md` の形式で返信をお願いします
