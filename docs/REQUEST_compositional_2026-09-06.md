# 依頼: 合成族(因子が独立に変わる部品)の生成 — 族をまたぐ汎化のための教師(2026-09-06)

宛先: PartMaker / 差出: AutoMetalSheet(ML 側)
背景: `docs/decisions/roadmap.md` 6.12、`docs/knowledge/06_rationality_eval.md` §6.B

## 0. 結論(依頼の要旨)

現在の 9 族(occt11〜21)は、族ごとに構造の因子(腕の有無と本数、タブ、壁、ビード/リブ、折り数、締結点数)が**固定の組合せ**で
束ねられている。学習器は「締結点配置 → 族の同定 → 族の型を出す」で損失を下げられるため、大域構造は族ごとの暗記になり、
未見の族では締結点を囲む凸形に退避する(8 族で学習 → occt20 タブブラケットの生成 30 部品すべてが湾数 0、教師は 2〜3)。

依頼は、**族という束を解いた「合成族」**を 1 つ作ること。1 部品ごとに因子を独立にサンプルし、族名で構造が予測できない教師にする。
既存 9 族は評価用にそのまま残す(合成族だけで学習して 9 族を測れば、「未見の組合せ」への汎化の直接測定になる)。

## 1. 生成器の設計原則

| 原則 | 内容 |
|---|---|
| **A. 因子の独立化** | 基板の形 / 腕の本数 / タブの数 / 折りの本数 / ビード・リブの有無 / 壁(チャンネル)の有無 / 締結点数 を、**互いに独立に**サンプルする。族名は 1 つ(例: `occt30`)で、内訳は params に記録 |
| **B. 本数の連続化** | 腕 0〜4、タブ 0〜2、折り 0〜3、締結点 2〜8。腕 0 = 平板、1 = タブ、2 = 細長い板、3〜4 = 分岐、が**同じ生成器**から出ること |
| **C. 同じ入力に複数の構造** | 同一の締結点配置(位置・法線・座面)に対して、成立する構造を 2〜3 種(例: 平板 / 分岐 / タブ付き)**変種**として出す(構造レベルの設計等価集合)。契約は依頼 A の `variants/` と同じ |
| **D. 凸包でない基板** | 締結点の凸包より内側にえぐれた輪郭、切欠き、非対称な余白を一定割合(30% 程度)で入れる。「締結点を囲む凸形」を退避解にさせない |

穴は今回の依頼に含めない(独立の因子として次回)。

## 2. 因子と値域(案。PartMaker 側で実現性に合わせて調整可)

| 因子 | 値域 | 備考 |
|---|---|---|
| 締結点数 N | 2〜8(一様) | 位置は基板上に配置。腕・タブの上に乗せるものと基板上のものを混ぜる |
| 腕 | 0〜4 本、長さ・幅は範囲から | 腕上に締結点が乗る場合も乗らない場合も |
| タブ | 0〜2、根元 R あり | occt20 の tab_bracket の要素 |
| 折り | 0〜3 本、折り位置は slack として自由(2 曲げ族と同じ) | 折れ角 60〜120° |
| ビード / リブ | 無し / ビード / リブ | 断面は既存サンプラー |
| 壁(チャンネル) | 無し / 片側 / 両側 | occt19 の要素 |
| 基板 | 凸包 + 余白(50%)/ えぐれ・切欠き(30%)/ 非対称余白(20%) | |
| 板厚・曲げ R・座面半径 | 既存どおり | |

**ゲート**は既存と同一(直線 / 円弧のみ、外形ループ 1、二面角 ≤ 150°、締結点が面上、座面が外形内)。

## 3. 数量と出力

- 部品 **2,000**(まず 600 で歩留まりと分布を確認 → 残り)
- 変種: 依頼 A と同じ契約(`variants/<part_id>__<knob>=<value>_mid.stp`、`params/`、`features/`、`manifest.json`)。
  **構造レベルの変種**(原則 C)は knob 名を `structure=<plate|branch|tab|channel>` とする
- ホールドアウト: `tools/_val_ids.json` の慣例で 30 部品
- params に因子の値(腕数・タブ数・折り数・壁・断面・基板の型)を必ず記録(評価で因子別に集計する)

## 4. 受け入れ確認(ML 側で行う)

- 往復(STEP → 外形テンソル → STEP)100%、座面 100%、自己整合 0%(既存の教師床の手順)
- 因子の独立性: params から「族名で構造が予測できない」ことを相互情報量で確認
- 学習: 合成族のみで学習 → 既存 9 族を評価(未見の組合せ)。構造署名(cos、湾数一致)と距離で判定

## 5. 期日と優先

- 優先度: 高(汎化の問いの本体)。ただし occt21 の取り込みと並行で構わない
- まず 600 部品で歩留まり報告をいただけると、値域の調整が早い
