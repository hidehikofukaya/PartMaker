# 3締結点ファミリ（実車007/011の再現）設計 — 2026-09-04

## 0. 目的とスコープ

`fill_mid_surf/A0072600002_AllCATPart` の実車部品 **007** と **011** を、合成側で
再現できる新ファミリ `three_point` を起こす。ユーザー指定の要点は3つ。

1. 締結点の**法線の多様性**を確保する — 「2点の法線が一致、もう1点が異なる」
2. 法線が一致する2点は**ある程度隣接**、3点目の位置関係には**ランダム性**がある
3. 2点と1点の間にある**曲げ線を補強するフランジ**が存在する

本書は実測 → 構造の同定 → 設計 → 判断 → 実装結果、の順。**実装済み**（§7）。

計測ツール: `tools/probe_real_topology.py`、`tools/probe_flange_steep.py`

## 2. 構造の同定 — 既存の掃引モデルに収まる

合成側（`occt_build`）は「全ての主曲げ軸が1本の方向 **w** に平行で、部品は w に
直交する平面内の中心線に沿って断面を掃引したもの」しか作れない。007/011 は
**そのまま収まる**。

- 主曲げの軸は 007 が −x、011 が −w の1方向のみ。→ 共通折り軸あり。
- フランジ根本Rの軸は主曲げ軸と直交するが、これは合成側でも同じ
  （フランジは**断面の一部**として掃引されるので、根本Rは自動的に主曲げ軸と直交する）。
  `probe_real_topology.py` の「共通折り軸なし」判定はフランジ根本Rを拾ってしまう
  ための誤判定であり、主曲げだけを見れば両部品とも単一軸。

**したがって新しい幾何エンジンは不要**。既存の `plan_general_two_point` を再利用する。

### 2.1 両部品に共通する骨格

```
      [対の2点]                    [単独の1点]
   同一パネル上                    別パネル上
        |                              |
        +---- 曲げ1本（90°前後） ------+
        |                              |
        +==== 側端フランジが跨いで補強 ==+
```

- 折れは**1回**。2点群と1点の間にちょうど1本。
- 対の2点は同一パネル。法線差 0.0°/0.5°。
- 単独点の法線差は 89.5°/90.0° = 折れ角そのもの。
- 側端フランジが曲げを跨ぐ（011は連続、007はコーナーで分断されるが役割は同じ）。

### 2.2 対の2点の「隣接」の質が2部品で異なる

| | 距離 | w方向成分 | 断面内成分 |
|---|---|---|---|
| 007 | 24.1mm | 11.9 (49%) | 21.0 (87%) |
| 011 | 36.8mm | 36.8 (**100%**) | 0.2 (1%) |

**分離の向きそのものが多様性の軸**。007は主に断面内（掃引方向）、011は完全に
w方向（帯幅方向）。設計ではこの配分を乱数で振る。

## 3. 最大の障害 — フランジの折れ角20°上限（解決済み）

`families.flange_part` は `max_fold_angle_deg > FLANGE_MAX_FOLD_ANGLE_DEG (20°)` を
弾く。CATIA時代の申し送り「最大折れ角20度以下ならフランジ、それ以外は
急でフランジ不成立」（2026-08-25）に由来する。

**しかし実車007/011のフランジは90°の曲げに載っている。** ユーザー裁定（2026-09-04）:
「実車が正。前職ではNG寄りだったが、この企業では成立させていた」。

OCCT版の実際の拘束は `occt_build._check_flange_radii` の**凹側クリアランス
`R_bend − h ≥ 2mm` だけ**で、折れ角そのものは効かない。壁は掃引断面の一部なので
曲げ上では「軸に直交する平面内の円環」になり、壁自体は曲がらないためである。

実測（`tools/probe_flange_steep.py`、各帯40試行）:

| 最大折れ角 | 試行 | 成功 | 成功率 | 落ちる理由 |
|---|---|---|---|---|
| 0–20° | 40 | 39 | 98% | — |
| 20–45° | 40 | 37 | 92% | `sample_flange` が側を選べない ×3 |
| 45–70° | 40 | 31 | 78% | 同 ×9 |
| **70–100°（実車帯）** | 40 | 31 | **78%** | 同 ×9 |
| 100–135° | 40 | 32 | 80% | 同 ×7 |

落ちる分は全て「2曲げで両側とも凹になり `sample_flange` が None を返す」ケースで、
**生成失敗（OCCTのエラー）はゼロ**。本ファミリは**1曲げ**なので必ず凸側を選べ、
歩留まりはこれより高くなる見込み。

→ **`FLANGE_MAX_FOLD_ANGLE_DEG` は本ファミリでは適用しない。**
既存 `flange` ファミリの扱いは §6 の未決事項。

## 4. 設計

### 4.1 構築手順（既存資産の再利用）

新しい掃引は書かない。次の3段で組む。

1. **骨格**: 対の代表点 P_a と単独点 Q の2点で、既存の
   `plan_general_two_point(..., target_folds=1)` を回す。これで中心線・曲げ1本・
   パネル2枚が決まる。折れ角は実車帯を狙って引く。
2. **フランジ**: 既存 `sample_flange` + `plan_flange_on_surface`。断面の一部として
   掃引されるので、曲げを跨ぐのは自動。20°ゲートのみ外す。
3. **対の相方**: P_a と同じパネル上に P_b を置く。パネル局所座標で
   `(Δs 掃引方向, Δw 帯幅方向)` を振り、下の拘束を満たすまで再抽選。

### 4.2 P_b の拘束（既存ルールを踏襲）

ユーザー指定（2026-09-04）: **締結点の余白と最小Rは従来ルールを踏襲**。

- 帯端まで `≥ min_bearing_radius_mm`（既存の必要平面ルール）
- 曲げの接線まで `≥ min_bearing_radius_mm`（同一パネル内に収める）
- パネルの掃引方向の端まで `≥ min_bearing_radius_mm`
- 中立面R最小 5mm、フランジ根本R 5–8mm は据え置き
  （実車011の根本R3.85は**採用しない** — 我々の下限を優先）
- `check_shape` の「締結点が面上にある」検査に P_b も通す（`MAX_FASTENING_OFFSET_MM = 0.1`）

### 4.3 帯幅の制約と帰結（**要判断**）

現行: `half_width = min(25.0, bearing_radius × U(1.0, 1.3))`、`bearing_radius = U(12.5, 25)`。
つまり帯幅は最大50mm、かつ余白ルールから

```
|Δw| / 2 ≤ half_width − bearing_radius ≤ 0.3 × bearing_radius
→ |Δw| ≤ 0.6 × bearing_radius ≤ 15mm
```

| 実車 | 必要 Δw | 現行で可能か |
|---|---|---|
| 007 | 11.9mm | ✅ 可 |
| 011 | **36.8mm** | ❌ 不可（帯幅61mmが必要） |

余白ルール自体（`half_width ≥ bearing_radius`）は触らない。効いているのは
**帯幅の上限50mm**（`MAX_HALF_WIDTH_MM = 25`）という別ルール。実車011の底パネルは
61mm。→ 本ファミリだけ比率と上限を広げるかが判断点（§6-①）。

### 7.3 トポロジの一致（生成品を `probe_real_topology.py` で再計測）

生成品も007/011と同じ骨格になっている:

```

tp_001: 面7 平面3 曲げ3  主曲げR27.8 折れ角84.3deg  主パネル[0,5]  曲げを跨ぐフランジ壁[3]
```

主曲げ1本・それに接する主パネル2枚・その曲げを跨ぐ側端フランジ壁1枚。011の
「連続して回り込む側端フランジ」と同型（007はコーナーで2枚に分断される版）。

### 7.4 再現できていない点（既知の限界）

**011型の「対が帯幅方向に36.8mm離れる」配置は作れない。** 到達したΔwは最大17.4mm。

理由は帯幅ではなく**アンカーが帯の中心線に固定されている**こと。掃引の中心線は
`point1`/`point2` そのもので定義されるので、対の一方は必ず帯の中心（w=0）に来る。
従来の余白ルールから相方の可動域は

```
|Δw| ≤ half_width − min_bearing_radius_mm ≤ 35 − 12.5 = 22.5mm
```

実車011のΔw=36.8mmを出すには `half_width ≥ 36.8 + 12.5 = 49.3`（帯幅98.6mm）が必要で、
今回合意した70mmを超える。実車007のΔw=11.9mmはレンジ内で再現できている。

解消するなら、締結点を中心線から外して帯を非対称に張る（`side_extension_mm` の
一般化）改修が要る。フランジが同じ引数を使っているので競合の整理が必要。

## 9. 011型（三角形分布）を別ファミリとして起こす

§7.4 で「011型は再現できていない」と書いた点を、ユーザー指示（2026-09-04）により
**007とは別の型**として実装した。007型と011型を**同数600部品ずつ、計1200部品**。

### 9.1 何が違うのか — 三角形らしさで測る

3点の配置を **三角形らしさ = 最小高さ / 最長辺**（0 = 一直線、0.866 = 正三角形）で測る。

| | 辺 | 三角形らしさ |
|---|---|---|
| 実車007 | 24.1 / 43.6 / 59.7 | 0.254（細長い） |
| 実車011 | 36.8 / 38.5 / 41.2 | **0.765（近正三角形）** |
| 合成 occt13（007型600件） | — | 0.036〜0.286（中央 **0.128**）、**0.30以上は0%** |

occt13 は67%が0.15未満で、実質「面上で直線的に並ぶ」型しか作れていなかった。

### 9.2 なぜ 007型の族では作れないのか

近正三角形にするには対を**帯幅方向にだけ**離す必要がある（実車011は断面内の隔たり
0.2mm・帯幅方向36.8mm）。さらに現実的な帯幅に収めるには、対が中心線を**またぐ**必要がある。

| 置き方 | 上限 | Δw=36.8 に要る帯幅 |
|---|---|---|
| 片方を中心線に固定（007型） | `Δw ≤ half_width − bearing` | **98mm**（非現実的） |
| 中心線をまたぐ（011型） | `Δw ≤ 2 × (half_width − bearing)` | **66mm**（実車61mm） |

またぐには対のどちらも中心線に乗れない。しかし掃引の中心線は `point1`/`point2` で
定義される。→ **掃引アンカーを対の中点として使い、実際の締結点2つを ±Δw/2 に置く。**
アンカー自身は締結点ではないので `annotated_points` から外す
（`GeneralTwoJointSpec.annotated_points`、None なら従来どおり）。

掃引の幾何は一切変えていない。アンカーは中心線上の1点として今までどおり機能する。

### 9.3 パラメータの決め方（200件ずつの総当たり）

| 設定 | 三角形らしさ（中央） | 辺（中央） |
|---|---|---|
| 閾値0.45 / R8-18 / slack0-18 | 0.64 | [38, 56, 57] |
| 閾値0.60 のみ | 0.67 | [41, 52, 53] |
| **閾値0.60 / R8-14 / slack0-10** | **0.73** | **[36, 47, 47]** |
| 閾値0.60 / 60-90° / R8-14 / slack0-10 | 0.73 | [41, 47, 48] |

脚が長い（slackが大きい・Rが大きく接線長が伸びる）と単独点までの距離が伸び、対の
広がりが帯幅で頭打ちになって細長い三角形になる。折れ角を60-90°に狭めても改善しない

## 11. 014型の作り直し — 細長いビードと帯幅の絞り

§10 の初版はユーザー指摘（2026-09-04）と実情が違っていた。指摘は2点。

1. ビードは**2つの締結点の間を通り、対の側は板小端まで**伸びる。孤立点の手前まで
   届く**細長いビード**。
2. フランジは2つ立つが、**孤立した1点の締結点の幅に合わせてフランジ幅が縮小**する。

### 11.1 実測（掃引方向へ走査、`tools/probe_section_profile.py`）

| パネル | 帯幅の推移 | 中央（ビード深さ） |
|---|---|---|
| 対のパネルA(28) | 50.1 一定 | **3.5 が板端まで一定** |
| 対のパネルB(11) | 50.1 一定 | **3.5 が板端まで一定** |
| 中間(21) | 50.0 → 49.4 → 46.6 → 41.8 → 36.8 → 32.0 → **28.9** | 4.4 → 3.8 |
| 単独点(63) | 27.4 一定 | 位置1.5で0.9 → **以降ゼロ** |

対の2点は帯幅方向の±14mmにあり、ビードは**その間を通る**ので座面を避ける必要がなく、
板端まで伸ばせる。逃げているのは孤立点の側だけ。絞りきった27.4mmは孤立点（⌀7.0）の
必要平面幅そのもの。

### 11.2 実装

`_sweep_tapered_bead`（`occt_build.py`）。掃引は必ず「対の側 → 孤立点」の向きに揃える
（族が `host_index=0` で固定）。

```
s=0(対の側の板端) ─ ビード断面 ─┬─ 曲げ ─┬─ 逃げ(ビード→平地) ─ 絞り(広い平地→狭い平地) ─ 狭い平地 ─ s=total(孤立点)
                                          s2                s3                          s4
  s3 = total − 2*座面R   s2 = s3 − ランアウト   s4 = s3 + 0.6*2*座面R
```

- 逃げと絞りは `_loft_runout`（`brepfill.Face` の要素ペア織り面）を流用。断面どうしの
  要素数が1対1で対応する必要があるので、絞った断面は `y_breaks` の**両端だけ**を
  詰め替えて作る（ビードのブレーク点はそのまま）。
- 曲げは剛体断面でしか掃引できないので、逃げ・絞りが曲げを跨ぐ構成は Infeasible で弾く。

ビードの寸法つまみを追加（`sample_bead(rng, half_width, top_width_range, depth_range)`）。
実車の「細長いビード」は開口7.8mm・深さ3.5〜4.4mmで、既定（頂部幅10〜40、深さ4〜10）
では太すぎる。**足の幅を支配するのは深さ**（壁の投影長 `depth/tan θ`）だった。

### 11.3 座面規則との衝突（ユーザー裁定 B）

ビードが中央を通るぶん、対は「ビードの足 + 座面R」だけ外へ出す必要がある。
`半幅 >= ビードの足 + 2*座面R`。実測した3案:

| 案 | 座面R | 対を置ける率 | 帯幅 | 実車50mm比 |
|---|---|---|---|---|
| A 規則据え置き | 12.5–14 | 21% | 71–80 | 1.5倍 |
| **B 溶接相当（採用）** | **7.5–11** | **50%** | **50–68** | **ほぼ一致** |
| C 中間 | 9–12 | 37% | 57–74 | 1.35倍 |

実車014の対は**溶接**（座面クリアランス7.6mm）で、12.5mm下限はボルト締結を想定した値。
ユーザー裁定（2026-09-04）: **この族の対だけ溶接相当まで下げる**。他族は12.5〜25mm据え置き。

### 11.4 潰した不具合

| 症状 | 原因 |
|---|---|

## 12. 014型の修正2件（ビュワー確認、2026-09-04）

生成品をビュワーで見たユーザーから2点の指摘。

### 12.1 フランジとビードを同じ方向へ出す

フランジの向きは「**裏側へ折る**」規則（`backside_direction`、2026-08-25のユーザー指摘:
表側へ伸ばすと相手部品・ボルト座面と干渉する）で決まっている。一方ビードの向きは
`_bead_lift` が「曲げ上でビード頂部の半径が最大になる側」を独立に選んでいたので、
両者が逆を向く部品が出ていた。

→ **ビードがフランジに合わせる**。`_bead_lift(..., forced=flange.direction)` を追加し、
その向きで中立面R最小を割るならその部品は Infeasible として引き直す。

実測（生成品を断面で確認）: ビードが存在する全区間でビードと左右の壁が同じ符号。

### 12.2 フランジの稜線をなめらかにつなぐ

帯幅の絞りを1段のルールド面で落としていたため、フランジの稜線が絞りの始点と終点で
鋭く折れていた。加えて**絞りの置き場所が間違っていた** — 孤立点の座面（端から
`2*bearing`）の中に絞りが食い込んでいた。

区間の並びを実車014に合わせて組み直した:

```
0 ─ ビード(広い) ─ 曲げ ─ 絞り(ビードは通ったまま) ─ ビード(狭い)
  ─ 逃げ(ビード→平地) ─ 平地(狭い、孤立点の座面) ─ total
```

- **絞りはビードが通っている途中**で起こす。実車014も絞りは中間パネル（ビードあり）で
  起き、孤立点のパネルは絞りきった一定幅（§11.1の実測表と一致）。
- 絞りは `smoothstep`（両端で傾き0）で **8刻み**に割る。1段だと稜線が両端で60°以上
  折れる。刻みの長さは最後の直線区間の80%（`TAPER_LENGTH_SHARE`）。
- 端から `3*bearing` は絞りきった平地にする（`TAPER_CLEAR_BEARINGS`）。孤立点は
  端から最大 `bearing` 手前に置かれ、その周り `bearing` が平地で要るため。

| エッジ（最大） | 136 | **303** |

刻みを増やした分だけ面が増える。1.2回は「孤立側の直線が短くて絞りと逃げが入らない」
