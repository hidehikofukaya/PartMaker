状態: **実装済み**（`families.compose_part`、`occt_build.build_general_two_point(arms, notches, side_extension_mm)`、`variants._structure_variants`）。§5 の裁定（2026-09-06）: 1 折り3本は外す、2 フランジの折れ角制限は外す、3 構造変種は腕上に締結点の無い部品だけ、4 切欠きは円弧と矩形、5 タブ溶接は実車相当。結果は `docs/REPLY_compositional_2026-09-06.md`。

## 0. 要旨

依頼は「族という束を解いた合成族」を 1 つ作ること。因子（基板の形／腕／タブ／折り／ビード・リブ／
壁／締結点数）を 1 部品ごとに独立にサンプルし、族名で構造が予測できない教師にする。

現状の 9 族はビルダーが 4 系統（掃引・分岐・チャンネル・絞りトレイ）に分かれていて、因子は
ビルダーごとに固定の束になっている。合成族を作るには**1 つのビルダーの上で全因子を切り替えられる**
必要がある。調査の結果、**掃引ビルダー（2 点族）を土台にして、そのパネルの側辺に分岐族の腕を
縫合する**のがもっとも少ない追加で全因子をほぼ覆う（§2）。今日の実証で「パネルの長い側辺の
一部に腕を縫合しても外形ループ 1 のまま」を確認した（`tools/probe_output/partial_sew.stp`）。

## 1. 因子 → ビルダーの対応（実現性）

| 因子 | 依頼の値域 | 実現方法 | 状態 |
|---|---|---|---|
| 折り（基板） | 0〜3、位置は slack | 掃引の `target_folds` 0/1/2 + slack | **0〜2 は既存**。3 は掃引の中心線ソルバ（2 曲げの閉形式）の拡張が要る → 第1期は 0〜2 |
| ビード／リブ | 無し／ビード／リブ | 掃引の既存サンプラー | 既存（リブは 1 曲げ以上、ビードは走行長が要る＝依存あり） |
| 壁（チャンネル） | 無し／片側／両側 | 掃引の**フランジ**（`side`, `both_sides`）＝側辺の壁 | 既存（折れ角 ≤ 20° の帯でしか成立しない制約を**外す**必要あり: フランジ成立条件は凹側クリアランスだけなので、急な折れでも高さを抑えれば立つ） |
| 腕 | 0〜4、長さ・幅 | **新規**: 掃引パネルの側辺（フランジの無い側）の一部を根本に、分岐族の腕（回転掃引 + 腕面）を縫合 | 実証済み（部分エッジへの縫合 OK）。腕どうし・腕とフランジの干渉は `_check_arm_clearance` |
| タブ | 0〜2、根元 R | 腕の輪郭 `tabs`（1285-18 のタブ + 根元 R） | 既存 |
| 締結点数 | 2〜8 | 掃引の 2 点（アンカー）+ 基板上の追加点（3 点族の `_place_pair_mate` の一般化）+ 腕の上の点（分岐族） | 一般化が要る（基板上の点は必要平面と折り位置の整合） |
| 基板の形 | 凸包+余白 50% / えぐれ・切欠き 30% / 非対称余白 20% | 帯幅 `half_width` と `side_extension_mm`（片側だけ広い＝非対称）は既存。**えぐれ・切欠き**は側辺への凹の切り欠き（角の逃げと同じブーリアン切削 `_relief_tool` の流用） | 非対称は既存、切欠きは小さな追加 |
| 板厚・曲げ R・座面半径 | 既存どおり | 既存 | — |

「腕 0 = 平板、1 = タブ、2 = 細長い板、3〜4 = 分岐」（原則 B）は、この土台では
「折り 0 の帯 + 腕 0」＝平板、「+ 腕 1」＝タブ付き、「腕 2 対辺」＝チャンネル状、「腕 3〜4」＝分岐、
と同じ生成器から出る。

## 2. 生成の流れ（案）

1. **基板**: 締結点 2 点（アンカー）を引き、折り数 0〜2 と slack で中心線を解く（既存）。帯幅と
   片側／両側の余白を独立に引く。30% でえぐれ（側辺の凹円弧、半径 5〜15）を 1〜2 か所入れる。
2. **断面特徴**: 無し／ビード／リブ／フランジ（片側／両側）を独立に引く。成立しない組合せ
   （リブ + 折り 0、ビード + 走行長不足、フランジ + 凹側クリアランス不足）は**その因子だけ**引き直す
   （他の因子は保つ → 因子の独立性を保ちつつ歩留まりを確保）。
3. **腕**: 0〜4 本を、フランジの無い側辺の空き区間に置く（根本幅 20〜50、折れ角 60〜120、R、長さ、
   輪郭 矩形／台形／タブ 0〜2）。腕上の締結点 0〜2。
4. **基板上の追加点**: 合計が N（2〜8）になるまで、必要平面を満たす位置に置く。
5. ビルド → 既存ゲート。不成立は理由を記録して**その因子から**引き直す。
6. params に因子（`factors: {folds, section, walls, arms, tabs, notches, margin_kind, points}`）を記録。

### 2.1 構造レベルの変種（原則 C）

同じ締結点で構造を変えるには、その締結点を保持できる構造だけが候補になる。腕の上の点は
腕が無いと保持できないので、**構造変種は「基板上の点だけの部品」で出す**（腕上の点を持つ部品は
腕の有無を変えられない）。変種の knob:

| knob | 内容 |
|---|---|
| `structure=plain` | 断面特徴・腕・切欠き無し |
| `structure=wall` | フランジ（片側／両側） |
| `structure=bead` / `rib` | 断面特徴 |
| `structure=arms` | 締結点の無い腕 1〜2 本を足す |
| `structure=notch` | えぐれ入りの基板 |

契約は依頼 A の `variants/` と同じ。

## 5. 裁定をお願いしたい点

1. **折り 3 本**は第1期から外してよいか（0〜2 で始め、必要なら第2期で拡張）。
2. **フランジ（壁）の折れ角制限**（現行: 最大折れ角 20° 以下の帯だけ）を合成族では外してよいか。
   実車では 90° 曲げにもフランジが載る（007/011 で確認済み）。成立条件は凹側クリアランスだけ。
3. **構造変種の範囲**: 上記 §2.1 のとおり「基板上の点だけの部品」に限ってよいか。
4. **えぐれの形**: 側辺の凹円弧（半径 5〜15、1〜2 か所）でよいか。矩形の切欠きも混ぜるか。
5. 腕の上の締結点の必要半径は既定（12.5〜25）でよいか、溶接相当（7.5〜11）を混ぜるか
   （タブ付きの腕は溶接相当が自然）。
