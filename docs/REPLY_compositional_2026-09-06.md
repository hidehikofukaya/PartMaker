## 2. 構造変種（原則 C）

`variants/<part_id>__structure=<label>_mid.stp`。腕の上に締結点の無い部品（388 / 600）だけが対象。
878 個（不成立 41）。

| label | 内容 | 個数 |
|---|---|---|
| plain | 断面・壁・腕・切欠き無し | 367 |
| nowall / wall | フランジを外す / 片側フランジを足す（フランジ側の腕は消す） | 268 / 57 |
| noarms / arms | 腕を外す / 締結点の無い腕 1〜2 本を足す | 95 / 61 |
| nonotch | 切欠きを外す | 30 |

依頼の `structure=<plate|branch|tab|channel>` に対しては、plain ≈ plate、arms ≈ branch/tab、
wall ≈ channel（片側）に相当する。同じ締結点で `bead`/`rib` を付け外しする変種は未実装。
