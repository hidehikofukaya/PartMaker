# タブ付きブラケット（実車1285-18）設計 — 2026-09-06

## 0. 結論: 絞りは無かった

前回の調査で「絞り壁（自由曲面34%）」と報告した面を面ごとに曲率で測ったところ、
**R3 の曲げ（B-spline で書かれた円筒）＋ほぼ平らな立ち上がり壁**だった。立ち上がりの
曲率半径は端で 150〜450mm、大部分は 1,000mm 超で平面とみなせる。1285-18 は平面＋円筒だけの
展開可能な部品で、既存のゲートを変えずに実車遵守で作れる。

ユーザー指示（2026-09-06）: 絞りは許容、実車遵守。裁定: 必要半径と最小Rは実車相当、
台の締結点は1〜2点、フランジの輪郭は矩形や台形で表現。

## 2. 構築モデル — 分岐ビルダーの拡張

`build_branch_part`（平面ハブ＋辺ごとの腕）に 3 つ足した:

1. **腕ごとの折る側** `side`（−1 = 裏側、既定。+1 = 表側）。立ち上がりは +1、フランジは −1。
   曲げ中心 `a + side·R·n`、先端方向 `outward·cosα + side·n·sinα`、回転軸は side で反転。
   腕面の法線 `cross(tip, axis)` は α=0 でハブ法線に連続する（どちらの側でも）。
2. **腕の輪郭の種類** `outline`:
   `{"kind": "tabs", "height_mm", "tabs": [[s, r], ...]}` = 立ち上がり + 上端の半円タブ、
   `{"kind": "trapezoid", "shrink_a_mm", "shrink_b_mm"}` = 先端が狭い台形（0 で矩形、隅 R）。
3. **腕の無い頂点の凸フィレット** `fillet_radius={頂点: R}`（`_fillet_corner_2d`）。
   両隣に腕が無い頂点だけに入れる（腕の根本エッジを短くしないため）。

ハブは五角形 `(0,0) (L,0) (L,g) (L−dx,W) (0,W)`。辺 0 が立ち上がり、辺 1（長さ g = 逃げ）、
辺 2 がフランジの折り線（`dx = (W−g)/tanβ`）、頂点 4 に R。腕どうしの角が無いので
既存の凹コーナーは発生しない。

## 4.1 タブの根元R（2026-09-06 追記）

半円タブの根元を直角に落とすと応力集中で裂けるので、根元に**最小Rの凹コーナー**（この族は R3）を
付けた（ユーザー指示）。凹Rの円は上端の直線とタブの円に外接し、中心は上端の外側
`(h + ρ, s_c ± sqrt(r² + 2rρ))`。タブが上端で占める片側幅は r から `sqrt(r² + 2rρ)` に広がるので、
タブ間隔と立ち上がりの端の余白はその幅で取る（`tab_footprint_mm`、`tab_top_section`）。

## 5. 申し送り

* フランジの丸底 R26 は「矩形／台形」で置き換えた（裁定）。
* 台の `other_hole` は締結点として `mounting_hole` 1〜2 点に読み替えた（裁定）。
* 立ち上がりの端の面取り（実車は左端で高さ 0→9 の斜め）は省いた。端は垂直。
