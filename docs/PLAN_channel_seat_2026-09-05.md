## 0. 何を作るか

ブラケット。ユーザー指定（2026-09-05）:

## 1. 実車の実測（`fill_mid_surf/A0072600529/144`、t=0.603）

```
            ウェブ 66.8 × 31.5  n=(0,0,-1)
   ┌──────────────────────────────┐
   │壁 88.0° R3.4                 │壁 88.0° R3.4     ← 溝(チャンネル)
   │  下辺は 43.5° の斜辺         │
   └───╲                          ╱───
        座面 44.8×31  86.1° R2.6      座面（同一法線 n=(0,-0.69,-0.73)）
        溶接2点（端から7mm、31mm間隔）
```

* 壁は上辺（ウェブとの曲げ線）が全長 66.8、下辺が斜辺。斜辺は y=−788.5 → −755.5 の
  33mm を深さ 45.0 → 76.4 で結ぶ（43.5°）。斜辺の浅い端はウェブの端より 9.5mm 外に出る。
* 座面はその斜辺から外へ 86.1° 折れる。両座面の法線はウェブの法線から 43.2°。
* 溶接は各座面に2点、外へ ≈21mm、両端から ≈7mm。ウェブに締結の注釈は無い
  （ユーザー: 一般にはウェブにも締結があるので**必須1点**にした）。
* 自由曲面 1.2%（曲げ角の縁のブレンドのみ）。平面＋円筒で作れる。

## 2. 構築モデル — 2段折り

分岐族（`branch_frames`）の「根本エッジを軸に回転掃引」を **2段**使う専用ビルダー
`OcctPartBuilder.build_channel_seat`（幾何は OCCT 非依存の `channel_seat_frames`）:

1. **ウェブ** = 長さ L（u方向）× 幅 W（v方向）の矩形。ハブ。
2. **壁** = ウェブの両長辺から α で裏側へ折る。壁の面は四角形
   `a2 → b2 → Q_b → Q_a`（上辺 = 曲げ線、下辺 `Q_a–Q_b` = 斜辺）。
   斜辺は u = `diag_start` から `diag_start + S_a·cosβ`、深さ `D0` から `D0 + S_a·sinβ`。
3. **座面** = 斜辺を軸に、壁の**外側**（壁の法線側）へ γ 折る。矩形 S_a × S_b、先端2隅 R4。

両壁は `v = W/2` の面で鏡像（壁B は斜辺の u 座標を `L − …` で反転する）ので、座面は
自動的に鏡像になる。

### 2.1 座面の法線を両側で一致させる

鏡像の2平面の法線が一致するのは、法線が鏡映面に乗るとき（v 成分 = 0）だけ。
座面法線 n(θ) = n₀cosθ + (d × n₀)sinθ（n₀ = 壁の法線、d = 斜辺方向、n₀ ⊥ d）なので

```
tanθ = −(n₀·v) / ((d × n₀)·v)
```

で γ = |θ| が**解ける**。`seat_fold_deg=None` を渡すとこの γ を使う。
実車（α=88, β=43.5）では γ = 88.5°（実車の 86.1° は座面同士が 5° ずれる。実測でも
両座面の法線は 2 桁目まで一致していた）。解いた γ が 55〜100° を外れる標本は捨てる。

したがって座面の傾き（ウェブ法線との角度）は α と β から決まる**従属量**で、
600部品で 17.6〜59.6°（実車 43.2°）。「台座の締結点は座面に対して一定の角度差」を
満たしつつ、その角度差自体が多様になる。

### 2.2 ③ 台形の向き

壁の折れ角 α < 90° なら壁は常に外へ開く（先端方向 = outward·cosα − n·sinα の
outward 成分が正）。**α ∈ [60, 88]** に固定して、ウェブが長辺になる配置を構造的に
排除した。

## 5. 実車との差（申し送り）

* **座面の締結点間隔**。実車は溶接で 31mm 間隔・端から 7mm。我々は既定の必要半径
  12.5〜15 を課すので座面の幅を 45〜70 に広げた。溶接相当（7.5〜11）にするかは未裁定
  （`three_point_span` は裁定済みで溶接相当）。
* **折り線の切れ目・切欠き**は省いた（指示）。
* **ウェブの締結点**は実車に注釈が無い。必須1点は一般論からの指定。
* 壁の側辺は直線（実車も直線。−y側 12.6°、+y側 30° の傾き）。
