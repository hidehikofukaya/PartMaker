## 3. 設計

### 3.1 幅方向に並ぶビード（`multi_bead_section`）

既存の `_bead_section` は帯の中央に 1 本だけだった。`_bead_bump(bead, lift, y_c, role)` で
1 本分の「足R - 壁 - 稜線R - 頂部 - 稜線R - 壁 - 足R」を任意の y に置けるようにし、
平地でつないで断面にする。全長を走るので走り出し・走り終わりのランアウトは要らず、
`_sweep_uniform` にそのまま渡せる。

**中心（y=0）は必ず平地で残す** — 掃引が解いた 2 点のアンカーがそこに載るため。したがって
ビードは中心から `座面半径 + 2mm` 外側から並べる。

### 3.2 側辺の壁と腕

合成族 第2期と同じ仕組み（`_compose_free_segments` + `_attach_side_arms`）を再利用した。
壁 0〜2（高さ 10〜25、締結点なし）、腕 0〜4（矩形／溶接タブ付き）。

### 3.3 締結点

アンカー 2 点（中心線上）+ 腕の上 + **平地の上**。平地は「ビードの間と外」で、
座面 2b が入る幅のものだけ使う。点どうしは 2b + 2mm 以上離す。最大 20。

## 4. 実装で分かったこと

| 事実 | 根拠 |
|---|---|
| **浅くて稜線Rの大きいビードは壁が反転する** | 壁は z = sb·sinθ から depth − sb·sinθ まで（sb = 稜線R·tan(θ/2)）。`depth ≤ 2·sb·sinθ` だと反転し、掃引すると法線が裏返って隣の面と **180 度**になる。実測でこれが失敗の 3 割。`_bead_bump` に `depth − 2·sb·sinθ > 0.2` の判定を入れた |
| 隅の逃げ（`_apply_corner_relief`）は無罪 | 外して試しても 180 度は同数だった。ビードを外すと 0 になった |
| ビードの位置（中央／片寄せ／対称）も無罪 | 3 通りとも同じ失敗数 |
| 単一ビードの `beads=` 経路は既存の `bead=` 経路より二面角が良い | 同じ断面で 0〜3 度 対 26.6 度 |
| **本数と 1 本あたりの大きさは従属する** | 帯幅が 120mm、座面が直径 25〜34mm なので、中心と外側の平地を引くと 4 本並べるにはビード 1 本の足幅を 6.5mm 以下にする必要がある。本数が多いほど頂部幅・深さ・稜線R・間隔を詰めるようサンプラを組んだ |
