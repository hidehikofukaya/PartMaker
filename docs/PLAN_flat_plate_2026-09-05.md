## 3. 設計

外形 = **締結点の凸包の各辺を `margin` だけ外へ平行移動して交わらせ、隅を
`corner_radius` で丸めたもの**。余白と隅Rは別物なので分けて持つ。

鋭い隅ではマイター点が棘になる（実車1285-20の凸包には約45°の隅がある。そこで
マイター点は余白の2.6倍まで伸びる）ので、**マイター上限**を設けた:

```
マイター距離 = margin / sin(内角/2)
  <= 1.8 * margin  → マイター点を corner_radius で丸める（実車の隅R相当）
  >  1.8 * margin  → 余白の半径 margin でそのまま回り込ませる
```

CADのストローク結合と同じ考え方。実車031の外形にR36.5/R49の大きな円弧があるのは、
この「回り込み」に相当する。辺は直線・隅は円弧だけなのでゲートAは自明に通る。

新しい掃引は書いていない。平板は掃引ではなく**平面＋外形ワイヤ**なので、
`OcctPartBuilder.build_flat_plate` を別立てにした（掃引経路は一切触っていない）。

4点なので、4点寄りの分布はむしろ実車に近い。
