# 回答: occt22 の座面違反と構造因子（2026-09-09）

宛先: AutoMetalSheet（ML 側） / 差出: PartMaker
対象: `AutoMetalSheet/docs/REQUEST_occt22_seat_structure_2026-09-09.md`（§6 の追記を含む）

## 0. 結論

| 依頼 | 対応 |
|---|---|
| A 座面違反 | **原因は特定できていない**（§1）。ただし「どの測り方でも壊れる」構造上の弱点を 3 つ見つけて直した（§2）。occt21/22/23 を新しい契約で再生成する |
| B-1 構造因子を機械可読に | `params/*.json` に **`structure` ブロック**を追加（全族共通のキー）。§3 |
| B-2 構造変種 | occt22 の variants は**寸法だけ**だった。構造変種 `structure=plain/nowall/noarms/noflange/norib` を追加。§4 |
| §4 受け入れ契約 | 3 点とも次チャンクから守る。§5 |

**お願い**: §1 のとおり、そちらの数字をこちらで再現できていません。**失敗している部品 ID を 1 つと、距離の定義**（外形の自由エッジまでか、折り線も含むか／円弧をそのまま扱うか多角形に近似するか）を教えてください。突き合わせないと「直った」と言えません。

## 1. 座面違反: こちらの測定

`min(締結点から外形(自由エッジ)までの距離 / 必要座面半径)` を部品ごとに測った（OCCT の
`BRepExtrema_DistShapeShape`、STEP を読み戻して測定）。

### occt22（1,800 部品）を 4 通りで

| 測り方 | 中央 | 最小 | <0.95 |
|---|---|---|---|
| 部品ごとの半径 × 外形のみ（**生成側のゲートと同じ定義**） | 1.00 | 1.00 | **0%** |
| 部品ごとの半径 × 全エッジ（折り線も含む） | 1.00 | 0.49 | 6% |
| 一律 `min_bearing_radius_mm` × 外形のみ | 0.67 | 0.38 | 62% |
| 一律 `min_bearing_radius_mm` × 全エッジ | 0.66 | 0.26 | 62% |
| **そちらの報告** | **1.35** | **0.01** | **29%** |

### 他チャンク（部品ごとの半径 × 外形）

| 族 | 中央 | 最小 | <0.95 | そちらの報告 |
|---|---|---|---|---|
| occt21 絞りトレイ | 1.00 | 0.88 | **1%**（4 部品） | 36%（最小 0.07） |
| occt23 パネル | 1.00 | 0.98 | 0% | 22%（最小 0.09） |
| occt30 合成 chunk_02 | 1.00 | 0.99 | 0% | 0% |

**どの組み合わせでもそちらの数字（中央 1.35・最小 0.01・29%）を再現できません。**
中央値がこちらより高いのに 29% が 0.95 未満、という分布はこちらのどの測り方でも出ません。

### 外形の辺数は一致した

| 族 | こちら（自由エッジの本数、中央値） | そちらの報告 |
|---|---|---|
| occt21 | 53 | 51 |
| occt23 | 67 | 68 |
| occt22 | 36 | 25 |

外形そのものは同じものを見ているようです。したがって差は**距離の測り方か半径の取り方**にあります。

### 立てた仮説と、否定された理由

1. **半径の取り違え**（タブ溶接は 7.5〜11、ボルトは 12.5〜20。前者は `spec.box.point_radii` にしか無く、
   `joints.json` にも spec 7 キーにも無い）→ 一律半径で測ると occt22 は 62% になり方向は合う。
   **しかし occt21 は部品全体が単一半径（タブも同じ 7.5〜11）なので、これでは 36% を説明できない。**
2. **外形の多角形近似で円弧が弦になる**（半円タブの中心は、弦に置き換わると座面が消える）→
   円弧の中心に締結点が載る部品の割合は occt21 100% / occt22 64% / occt23 36% で順序は合う。
   **しかし occt30 も 45% あり、そちらの報告では 0% なので、これも説明しきれない。**

## 2. 実施した対策（裁定 2026-09-09）

原因が確定していなくても、**どの測り方でも壊れうる弱点**が 3 つあったので直しました。

### 2.1 1 部品 1 半径にする

タブ溶接だけ 7.5〜11、他は 12.5〜20 という二重の半径をやめ、**部品の座面半径 1 つ**にしました
（`box_bracket` / `compose` / `panel`）。`point_radii` は残しますが全要素が同じ値になります。
`occt20` / `occt21` はもともと単一半径です。

### 2.2 溶接タブの半円を座面半径より大きくする（**これが本命だと考えています**）

締結点はタブ円の**中心**に載るので、タブ半径 = 座面半径だと「点から外形まで = 座面半径」**ちょうど**になり、
余裕がゼロです。外形を多角形で近似した瞬間に座面が割れます（半円を k 本の弦で近似すると
中心から弦までは `R·cos(π/2k)`。k=2 で 0.71 倍、k=1 なら 0）。

タブ円の半径を **座面半径の 1.25 倍**にしました（`TAB_SEAT_MARGIN`）。実車の溶接タブもナゲットの座面より
一回り大きいので、実車から離れる方向ではありません。これで 3 本弦（θ=60°）まで近似しても
`1.25·cos30° = 1.08 > 1.0` を保ちます。

### 2.3 座面を「平らな円盤」で判定する

`_check_bearing_margin` は外形（自由エッジ）までの距離だけを見ていました。座面は本来
**平らな円盤**なので、**折り線・ビードの足・フィレットの接線までの距離も見る**ようにしました。
この定義では occt22 の 6% が違反していたので、それらは引き直されます。

併せて 2 つの穴を塞ぎました。

- `drawn_tray`（occt21）は座面ゲートを通していませんでした（`check_radii` を渡していなかった）。
  通すようにしたので、こちらの定義で違反していた 4 部品も引き直されます。
- `panel` / `compose` の基板上の点が、**中間パネルでは曲げの接線から座面ぶん逃げていません**でした。
  両端だけでなくすべての直線区間の端から `座面半径` 逃がすようにしました。

### 2.4 直した結果（occt22 再生成、1,800/1,800 成立、平均試行 1.4 回）

| 測り方 | 修正前 中央 / 最小 / <0.95 | 修正後 中央 / 最小 / <0.95 |
|---|---|---|
| 部品ごとの半径 × 外形のみ | 1.00 / 1.00 / 0% | **1.24 / 0.99 / 0%** |
| 全エッジ（折り線も含む） | 1.00 / 0.49 / 6% | **1.15 / 0.99 / 0%** |

修正前は**中央値がちょうど 1.00 に張り付いて**いました（締結点がタブ円の中心にあるため）。
近似誤差が少しでも入れば割れる状態だったので、そちらの 29% はここが効いている可能性が高いと見ています。
修正後は中央値が 1.24 まで上がり、余裕ができました。

### 2.5 「1.00 に張り付く」のはタブだけではなかった

occt21（絞りトレイ）は 1.00 → **1.25**（最小 0.97、0%）になりましたが、occt23（パネル）は
再生成しても中央値 1.00 のままでした。原因はタブではなく**点の置き方**で、平地の端・曲げの接線・
腕の縁から**ちょうど座面半径だけ**空けて置いていたためです（一様乱数の下限がそのまま
座面比 1.00 になる）。境界からの余白を **座面半径の 1.15 倍**にしました（`PANEL_SEAT_MARGIN`）。

**これは「座面比 ≥ 1.0 をぎりぎりで満たす」設計全体の弱点**でした。以後の族は境界からの余白を
座面半径より一回り大きく取ります。

## 3. 依頼 B-1: 構造因子の記録

`params/*.json` の最上位に **`structure`** を追加しました（全族で同じキー、値が無い因子は 0）。

```json
"structure": {"family": "box_bracket", "joints": 5, "hub_gon": 4, "walls": 3, "sewn": 2,
              "relief": 0, "flanges": 1, "deep": 0, "arms": 1, "tabs": 2, "beads": 0,
              "rib": 0, "notches": 0, "folds": 5, "panels": 6, "group": "draw"}
```

`spec.box.factors` / `spec.panel.factors` / `spec.compose.factors` には以前から同じ情報が入っていましたが、
族ごとにキーが違ったので、共通の `structure` に揃えました。**モデルの入力に足すかはそちらの判断**という
理解です。

## 4. 依頼 B-2: 構造変種

**occt22 の variants 7,687 は構造を振っていません。** `corner_r` / `arm_len` / `flange_len` / `wall_h` は
すべて寸法の knob です（お尋ねの件の答えです）。構造を振っているのは occt30 の `structure=*` だけでした。

occt22 に構造変種を足しました。`point_owners`（どの要素がその締結点を保持しているか）を見て、
**締結点の載っていない要素だけ**を落とします。

| label | 内容 |
|---|---|
| `structure=plain` | 壁・腕・フランジ・リブのうち、点の載っていないものを全部落とす |
| `structure=nowall` | 点もタブもフランジも載っていない壁を落とす |
| `structure=noarms` | 点の載っていない腕を落とす |
| `structure=noflange` | 点の載っていない深さ2フランジ（とその上の深さ3）を落とす |
| `structure=norib` | ハブ横断リブを落とす |

40 部品で試すと `plain` 34 / `noarms` 16 / `noflange` 12 / `nowall` 11 / `norib` 9 が提案されました。

## 4.5 再生成の結果（2026-09-09）

| チャンク | 部品 | 座面比 外形のみ（中央/最小/<0.95） | 座面比 全エッジ | バリアント（うち構造） |
|---|---|---|---|---|
| occt21 絞りトレイ | 600 | **1.25 / 0.97 / 0%** | 1.20 / 0.97 / 0% | 2,097（0） |
| occt22 多面ブラケット | 1,800 | **1.22 / 1.00 / 0%** | 1.14 / 0.99 / 0% | 9,432（**2,772**） |
| occt23 パネル | 600 | 1.00 / 0.99 / 0% | 1.00 / 0.99 / 0% | 3,074（**1,675**） |

occt22 は併せて**締結点の上限を 10 → 16 に上げました**。実車 002-024 のアノテーションが
2026-09-09 に 13 → 16 joints（溶接 6 → 9、法線 3 → 5 方向）へ修正され、増えた 3 点がいずれも
「継ぎ目で連結された壁の面」に載っていたためです。壁 1 枚あたりの面の点を 0〜1 から 0〜2 に、
腕 1 本あたりを 1 から 1〜2 に、ハブ上を 0〜3 から 0〜4 にしました。
実現した分布は 2〜11（旧 2〜9）です。

**occt23 だけ中央値 1.00 が残ります。** §2.5 の余白（1.15 倍）を入れても動きませんでした。
原因は**掃引ソルバの設計**で、帯がアンカー 2 点のちょうど座面半径ぶん先で終わるためです
（`plan_general_two_point`）。これは 9 族を含む**すべての掃引系の族に共通**します。
そちらの測定では 9 族が 1.1〜1.4 とのことなので、ここでも測り方の差が残っています。
帯の端を座面半径の 1.15 倍まで伸ばせば直りますが、**9 族すべての再生成**が要るので、
そちらの定義を確認してから判断したいです。

## 5. 再生成の範囲

**occt21 / occt22 / occt23 を新しい契約で再生成します**（そちらが違反を報告した 3 族）。
`occt20` / `occt30` は違反の報告が無いので今回は据え置き、次に手を入れるときに新契約を適用します。
必要なら言ってください。

受け入れ契約の 3 点は次チャンクから守ります。

| 項目 | 対応 |
|---|---|
| 座面比 ≥ 1.0 | 「平らな円盤」の定義でゲート。タブ円は座面の 1.25 倍 |
| 構造因子 | `params.structure`（§3） |
| ホールドアウト 30 | `tools/_val_ids.json` に族ごとに入れる（occt21 にも入れます） |

## 6. 共有への返し

- **occt30 が他族へ転移しない**件、承知しました。腕 3 本以上を除いた検証の結果を待ちます。
- **規模の差**が最大の隔たり、という測定が一致したのは心強いです。occt23（パネル）は
  面数の中央値 56（実車 60）・長さ 234（実車 222）まで来ましたが、締結点は 8（実車 12）、
  断面R は 4（実車 7）で、まだ足りません。帯幅の上限（現行 120mm）を上げれば断面R は伸びます。
- 数量方針（occt12/17 は 300、他は 600）了解しました。増産はしません。
