# 絞りトレイ（実車002-057）設計 — 2026-09-06

## 0. 経緯

実車 `A0072600002/057` は「底板の4辺に壁が立つトレイ」に見えたが、面の隣接関係と主曲率を
測ると**底板＋斜面（折れた床）＋左右の側壁が一体の絞りシェル**で、腕（1本曲げの板）は
後壁と棚の2本だけだった。最初に作った「腕4本＋角の逃げ」版は形状を取り違えていたので破棄した。

ユーザーの展開図（2026-09-06、2版）:

- 赤＝外形、**緑＝絞り線**（ハブの角から Y 字: ハブ–壁の境界2本と、壁どうしの継ぎ目1本。
  2版では左右両方の角に継ぎ目がある）、**青＝曲げ線**（タブ）。
- まず緑を絞ると、ハブに対して斜めの継ぎ目でつながった壁ができる。次にハブが器の底になる
  向きにタブを曲げる。左の壁は「やや絞り気味の曲げで境界が曖昧」＝我々のモデルでは右壁と
  同じ「継ぎ目つきの壁」。
- 「腕を4本生やしてから連結する手法は前に大失敗しているので、**あらかじめつないでから
  フィレット**するのが理想」。

裁定: 壁の角度は独立に振る。締結は絞り壁にタブ溶接（各2〜3）、曲げタブに溶接1〜2、
ハブに穴2。壁の上端は実車相当（高い方の壁が継ぎ目へ向けて細る）。

## 1. 実測（126×173×79、面24、自由曲面11%）

| 面 | 何と接しているか | 主曲率 |
|---|---|---|
| 底板（平面） | R38.7 折り線→斜面、R14.2→後壁、R8.7→左壁、R9.7→右壁 | — |
| 斜面（平面、32°） | 底板、棚（R10.7）、**左壁（R8.7）、右壁（R6.2）** | — |
| 左壁 / 右壁（平面。右壁は R1000 で実質平面） | 底板と斜面の両方に根本フィレットで接する | — |
| 角のパッチ（B-spline ×4） | 壁の根本フィレットが折り線を回る所 | **R8.7 × R33〜65 の二重曲率＝トーラス状** |
| 後壁 / 棚 | 曲げ1本だけ | — |

角の二重曲率は「壁の根本 R が折り線の R38.7 に沿って回る」ことで生じる絞りで、CAD の
エッジフィレットが頂点で作るブレンドそのもの。

## 2. 構築モデル — つないでからフィレット

`OcctPartBuilder.build_drawn_tray`（純幾何は `drawn_tray_frames`）:

1. **ハブ**（凸四角形 v0..v3、辺2 にタブの根本頂点、v2 に辺1 と直角の短辺）。
2. **壁 B**（辺0、前）、**壁 A**（辺1、右）、**壁 C**（辺3、左）を平面として作る。
   A–B は頂点 v1 から、C–B は頂点 v0 から出る**2平面の交線＝継ぎ目**で互いにトリム。
   継ぎ目の端 P は「2枚の壁の上端のうち低い方」に置き、高い方は上端を P へ向けて
   細らせる（実車の側壁が斜面の先で細るのと同じ）。
3. 鋭いエッジのまま縫合し、**共有エッジ5本**（ハブ–A、ハブ–B、ハブ–C、継ぎ目2本）に
   `BRepFilletAPI_MakeFillet`。頂点 v0・v1 のブレンド面が絞りに相当する。
4. **曲げタブ**（辺2、台形/矩形）を回転掃引で足し、全部を縫合。

### 2.1 収束とゲートの条件（実測で決めた3つ）

| 条件 | 理由 |
|---|---|
| **フィレット半径は3本とも同じ** | 半径が違うと頂点ブレンドの縁が自由曲線になり、「エッジは直線と円弧だけ」の出力契約（ゲートA）を破る |
| **継ぎ目の端に、継ぎ目に直交するノッチ**（長さ = 2·R·tan(θ/2) + 4） | 上端が継ぎ目に斜めに当たると、フィレットの終端が楕円で切られてゲートAを破る。ノッチ長が接線長+2 だとフィレットの帯がノッチの角に触れて OCCT が収束しない（失敗12件中12件が2倍で収束） |
| **v2 に辺1 と直角の短辺** | 斜めの辺2 でフィレットの終端が切られないように |

結果: 80件中 77〜79 が成立（収束しないもの 1〜2、ゲートA 0〜1。いずれも引き直し）。

## 5. 申し送り

* 出力に**トーラス／B-spline のブレンド面**が入る唯一の族。面ラベルは `draw_fillet`（円筒）
  と `draw_corner`（頂点ブレンド）。features v2 の `faces[].geo` にそのまま出る。
* 実車の「斜面→棚」の2段折りと舌は、2版の展開図には無いので作っていない（1版の
  `step` 輪郭はビルダーに残してある）。
* 実車の壁は斜面の先まで回り込むが、我々は継ぎ目の端で細らせて止める。
